Privacy

This site is a personal real-estate research dashboard. Profile edits and an optional Google Maps browser API key are stored locally in your browser using localStorage. The site itself does not transmit these values to a custom backend because no custom backend is present.

If Google Maps is enabled, map requests are sent to Google Maps Platform under Google's applicable privacy terms. Property listing images are loaded from their original listing hosts, so those hosts may receive normal browser requests.

Nearby infrastructure is requested from the public OpenStreetMap Overpass API using the catalog area, without sending your investment profile or Google key. The provider receives normal browser request metadata. POI results are cached locally for up to seven days. Leaflet map imagery is requested from Esri. The catalog and update status are fetched from this public GitHub Pages site on load and every five minutes.

Do not enter passwords, banking credentials, or unrestricted server API keys into this site.
